Étape 1 : Analyse des séquences target sur IMGT HighV-QUEST

La première étape consiste à soumettre les séquences obtenues par séquençage Sanger à IMGT/HighV-QUEST, un outil spécialisé dans l’annotation des régions variables des immunoglobulines (Ig) et des récepteurs des cellules T (TR), incluant les fragments de type scFv.

💡 Rendez-vous sur le site officiel de l'outil IMGT → ici.

  1. Depuis l’accueil, cliquez sur "Tools", puis sélectionnez IMGT/HighV-QUEST.
  2. Connectez-vous ou créez un compte gratuitement.
  3. Une fois connecté, vous serez redirigé vers le formulaire de soumission.
  4. Remplissez les champs suivants :
    • "Analysis title" : nom que vous souhaitez donner à votre analyse
    • "Species" : espèce concernée (ex. : Homo sapiens)
    • "Receptor type or locus" : type de récepteur (Ig ou TR)
    ✅Importez vos séquences au format .fasta ou .fastq, ou collez-les dans la zone prévue.
    ✅Cochez les options d’e-mail pour suivre l’état de l’analyse.
    ✅Conservez les paramètres par défaut, mais cochez "Yes" pour le paramètre “Analysis for single chain fragment (scFv)”.
  5. Cliquez sur "Start" pour lancer l’analyse.
  6. Vous recevrez un mail lorsque l’analyse sera terminée (si vous avez coché cette option).
  7. Allez dans l'onglet Analysis history.
  8. Téléchargez le dossier compressé des résultats (dans la colone action).
  9. Assurez-vous que le fichier 3_Nt-sequences.txt est présent.

Étape 2 : Connexion à ABTheroMap

Une fois l’annotation effectuée, lancez l'interface d'ABTheroMap et cliquez sur "Analyse" dans la barre de navigation.

  • Si vous n’êtes pas connecté, vous serez redirigé vers la page de connexion.
  • En cas de première connexion, suivez le lien "Inscrivez-vous" pour créer un compte.
  • Une fois connecté, retournez dans "Analyse" pour accéder au formulaire.

Vous pouvez également vous connecter en cliquant sur "Connexion" dans la barre de navigation.

  • Vous serez redirigé vers un page permettant de choisir entre se connecter et s'inscrire.
  • Si vous possédez un compte, cliquez sur le bouton "Se connecter", vous serez redirigé vers la page de connection.
  • En cas de première connexion, cliquez sur le bouton "S'inscrire" pour créer un compte.
  • Une fois connecté, retournez dans "Analyse" pour accéder au formulaire.

Étape 3 : Configurer les paramètres d'alignement

Vous arriverez sur une page contenant un formulaire à remplir. Ce formulaire permet d'importer vos données ainsi que de définir les paramètres que vous souhaitez utiliser pour l'alignement des séquences.

  1. Indiquez un titre et une description.
  2. Définissez les paramètres BLAST :
    • Couverture minimale (%)
    • Valeur de E-value
    • Nombre de gaps autorisés
    • Longueur minimale d’alignement
    • Pourcentage d’identité
  3. Importez les fichiers :
    • 3_Nt-sequences.txt d’IMGT (séquences Sanger)
    • Fichier FASTA des séquences NGS (base BLAST)

Si les formats de fichiers importés ne sont pas correct et que vous lancez l'analyse, vous serez redirigé sur cette page de formulaire et un message d'erreur s'affichera

Étape 4 : Lancer l'analyse

Cliquez sur "Lancer l’analyse". Une page de chargement s’affiche avec le titre, la description et l’heure de démarrage. Une fois terminé, un bouton "Voir analyse" apparait sur la page de chargement, cliquez dessus pour afficher les résultats.

Étape 5 : Affichage des résultats

Lorsque le bouton "Voir résultats apparait sur la page de chargement, l'alignement des séquences est terminé. Cliquez sur ce bouton pour visualiser les résultats

La page de résultats contient :

  • Un tableau de clones triés par nombre de correspondances (matches) décroissantes

→ Lorsque vous cliquez sur l'id d'un clone, vous serez redirigé automatiquement vers une page de résultats détaillés du clone.

Cette page contient :

  • Séquences VH et VL du clone selectionné
  • Diagramme de Venn illustrant la répartition des séquences NGS alignées (VH uniquement, VL uniquement, ou les deux)
  • Deux tableaux BLAST (VH et VL) représentant les résultats d'alignement de ces séquences sur les séquences de la base de données
    • qseqid : identifiant de la séquence requête (query) utilisée pour l'alignement.
    • sseqid : identifiant de la séquence cible (subject) avec laquelle la requête a été alignée.
    • Identité (%) : pourcentage de similarité (identité) entre la séquence requête et cible.
    • Longueur : longueur de l’alignement entre les deux séquences.
    • Mismatch : nombre de différences (mismatches) entre les séquences alignées.
    • Gap open : nombre de gaps introduits dans l’alignement.
    • qstart : position de début de l’alignement sur la séquence requête.
    • qend : position de fin de l’alignement sur la séquence requête.
    • sstart : position de début de l’alignement sur la séquence cible.
    • send : position de fin de l’alignement sur la séquence cible.
    • e-value : probabilité d’obtenir cet alignement par hasard — plus elle est faible, plus l’alignement est significatif.
    • Bitscore : score normalisé indiquant la qualité de l’alignement (plus il est élevé, mieux c’est).
    • qcovs : pourcentage de la séquence requête couverte par l’alignement (Query Coverage) — couverture de l'alignement.

Étape 6 : Téléchargement des résultats

Sur les pages de résultats, vous pouvez télécharger le diagramme de Venn au format .png et les tableaux de résultats aux formats .csv ou .xlsx.

Étape 7 : Historique des analyses

Grâce au système de connexion, chaque utilisateur dispose de son propre historique. En vous reconnectant à votre session, vous pouvez accéder à l’ensemble des analyses que vous avez effectuées depuis la création de votre compte.

✅Cliquez sur votre nom d’utilisateur en haut à droite et accédez à "Mon historique".

✅Vous y trouverez le résumé de toutes vos analyses : date/heure de l'analyse, nom, description, paramètres d'alignement choisis, état de l'analyse et résultats.

✅Vous trouverez également pour chaque analyse, un émoicône corbeille "🗑️" permettant de supprimer l'analyse de l'historique. Une fois supprimée, cette action est irréversible, vous n'aurez plus accès à l'analyse supprimée.

Étape 8 : Déconnexion

Pour vous deconnexter de votre session, deux choix s'offres à vous.

  • Cliquer sur votre nom puis sur le bouton "Déconnexion"
  • Cliquer sur le logo power ⏻ à côté de votre nom d'utilisateur

Dans les deux cas, vous serez redirigé vers une page de confirmation. Cliquez sur "Oui" pour vous déconnecter de l’outil.
